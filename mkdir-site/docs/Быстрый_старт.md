# Быстрый старт

Добро пожаловать в руководство по быстрому старту! В этом разделе вы узнаете, как интегрировать в вашу игру `HTML5 Ultra Pack` всего за несколько простых шагов.

## Предварительные требования

Прежде чем начать, убедитесь, что вы:

- Установили GameMaker версии [2024.8](https://releases.gamemaker.io/release-notes/2024/8)
> Расширение разрабатывалось и тестировалось на этой версии. Ничто не мешает вам попробовать другие версии, но я не гарантирую, что все будет работать корректно
- Скачали [.yymps расширение](https://github.com/KEsHa0cHoKE/HTML5-Ultra-Pack/releases)

***

## Установка расширения

1. **[Перетащите файл](https://manual.gamemaker.io/beta/en/IDE_Tools/Local_Asset_Packages.htm)** `.yymps` в ваш проект

2. **[Установите](https://manual.gamemaker.io/lts/en/Settings/The_Room_Manager.htm)** `__rmInit` в качестве стартовой комнаты

3. **[Перейдите](https://manual.gamemaker.io/lts/en/Settings/Game_Options/HTML5.htm)** в `Game Options - HTML5 - Graphics` и установите следующие настройки:
    - **Centre Game In Browser Window**: `true`
    - **WebGL:** `Required`
    - **Scaling:** `Full scale`

4. **[Перейдите](https://manual.gamemaker.io/lts/en/Settings/Game_Options/HTML5.htm)** в `Game Options - HTML5 - General` и установите следующие настройки:
    - **Для Yandex Games SDK**:
        - **Included file as index.html:** `Use Default`
        - **Loading bar extension:** `CustomLoadingSpinner`
    - **Для Playgama Bridge SDK**:
        - **Included file as index.html:** `playgama-bridge-index.html`
        - **Loading bar extension:** `Use Default`

***

## Базовая настройка

- **Настройте макросы** в скрипте [YGsettings](YGsettings.md):

    ```js
    // Выберите режим SDK
    #macro YG_MODE E_YG_MODE.YANDEX_GAMES // или E_YG_MODE.PLAYGAMA

    // Установите начальную комнату вашей игры
    #macro YG_FIRST_ROOM r_test // замените на ассет вашей начальной комнаты

    // Установите язык для тестовых билдов
    #macro YG_DEBUG_LANGUAGE "ru" // Например "en"
    ```

- **Инициализируйте переменные**, которые требуется сохранять между игровыми сессиями в скрипте [YGsettings](YGsettings.md):

    ```js
    // Инициализация переменных
    YG.data.max_score = 0;
    YG.data.player_skin = "default";
    YG.data.tutorial_completed = false;
    YG.data.available_items = ["shield", "sword", "bottle"];
    YG.data.lvls_data = {lvl_1: {score: 0, stars: 0}, lvl_2: {score: 0, stars: 0}};
    ```

## Использование SDK

После успешной инициализации игра сама перейдёт в вашу начальную комнату.
После этого вам будет доступна глобальная структура(`Struct`) `YG`, вот несколько стандартных сценариев использования:

### Проверка языка

```js
// Локализация текста
var _text = ""
if (YG.lang == "ru") {
    _text = "Привет, мир!";
} else if (YG.lang == "en") {
    _text = "Hello, world!";
}

draw_text(x, y, _text)
```

### Работа с данными

```js
// Обновление игровых данных
YG.data.level = 10;
YG.data.score = 20000;
YG.data.coins = 100;

// Сохранение данных на сервер
YG.storage.data.send();
```

### Работа с рекламой

```js
// Если можно показать полноэкранную рекламу
if (YG.adv.interstitial.is_showable()) {
    pause_game(); // Ставим игру на паузу
    YG.adv.interstitial.show(function() {  // Показываем полноэкранную рекламу
        continue_game(); // Этот код выполнится после закрытия рекламы
    });
}
```

``` js
// Показ ревард-рекламы
YG.adv.reward.show(
    function() {
        // Игрок досмотрел рекламу до конца
        obj_player.coins += 100;
    },
    function() {
        // Игрок закрыл рекламу раньше времени
        show_debug_message("Реклама закрыта преждевременно");
    }
);
```

``` js
// Показать баннер
YG.adv.banner.show();
// Cкрыть баннер
YG.adv.banner.hide();
```

### Управление аудио

```js
// Получение текущей громкости
var _currentVolume = YG.audio.getVolume();

// Установка новой громкости
YG.audio.setVolume(_currentVolume+0.1);
```

## Тестирование

Для тестирования функций SDK платформ:

- Запустите игру в тестовом режиме
- Используйте debug-настройки для имитации поведения на реальных платформах (фейковая реклама, сохранения, mute аудио и т.д.)
