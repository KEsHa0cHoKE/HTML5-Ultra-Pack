# Реклама

`adv` предоставляет модули для работы с рекламой

## Модули

| Модуль                              | Тип      | Описание                        |
| ----------------------------------- | -------- | ------------------------------- |
| [Interstitial](interstitial.md) | `Struct` | Полноэкранная реклада           |
| [Reward](reward.md)             | `Struct` | Реклама за вознаграждение       |
| [Banner](banner.md)             | `Struct` | Баннерная реклама (поверх игры) |

## Методы

| Метод     | Возвращаемый тип | Описание                                                                                                                                                  |
| --------- | ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| is_active | `Bool`           | Возвращает, показывается ли сейчас реклама, или предупреждение о скором показе рекламы, или ревард, или ожидается ответ сервера на запрос показать ревард |

---

### `is_active()` → `Bool`

> Возвращает, показывается ли сейчас реклама, либо предупреждение о скором показе рекламы, либо ревард, либо ожидается ответ сервера на запрос показать ревард.

**Пример:**

```js
if (YG.adv.is_active()) {
    show_debug_message("Реклама сейчас активна");
} else {
    show_debug_message("Реклама неактивна");
}
```
