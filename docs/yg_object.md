# Документация по объекту YG

YG - это глобальный объект, предназначенный для интеграции с Yandex Games SDK и PlayGama Bridge. Он предоставляет функции для работы с сохранениями, рекламой, аудио и платформо-специфичной информацией.

## Структура объекта

- `YG.data` - Структура для хранения пользовательских данных
- `YG.stats` - Структура для хранения статистики
- `YG.flags` - Структура для хранения флагов
- `YG.lang` - Язык пользователя, который запустил игру в формате [ISO 639-1](https://ru.wikipedia.org/wiki/Список_кодов_ISO_639-1). Например "ru" или "en"
- `YG.device_type` - Тип устройства (E_DEVICE_TYPE.PC или E_DEVICE_TYPE.MOBILE)
- `YG.is_release_build` - Булевое значение, указывающее, запущена игра в тестовом режиме, или это собранный билд
