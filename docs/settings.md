# Настройки (YGsettings)

Файл `YGsettings.gml` содержит конфигурационные макросы для настройки поведения YG-интеграции вашем проекте.

## Основные настройки

### `YG_MODE`
Тип используемого SDK: `E_YG_MODE.YANDEX_GAMES` или `E_YG_MODE.PLAYGAMA`

```gml
#macro YG_MODE E_YG_MODE.PLAYGAMA // Используемый SDK. Яндекс либо Плейгама
```

### `YG_FIRST_ROOM`
Стартовая комната вашей игры.

```gml
#macro YG_FIRST_ROOM r_init // Стартовая комната вашей игры
```

### `YG_DEBUG_LANGUAGE`
Язык, который будет использован для тестовых билдов и помещён в `YG.lang`.

```gml
#macro YG_DEBUG_LANGUAGE "ru" // Язык, который будет использован для тестовых билдов
```

## Настройки сохранений

### `YG_SAVING_ACTIVE`
Сохранять данные на сервер в релизном билде (если false, то прогресс не сохраняется вообще).

```gml
#macro YG_SAVING_ACTIVE true // Сохранять данные на сервер в релизном билде
```

### `YG_SAVING_DEBUG_ACTIVE`
Имитировать сохранение/загрузку прогресса на сервер в тестовом билде (сохраняет/загружает сейвы в локальные файлы).

```gml
#macro YG_SAVING_DEBUG_ACTIVE true // Имитировать сохранение/загрузку прогресса в тестовом билде
```

### `YG_SAVING_DEBUG_PERIOD`
Время сохранения данных в секундах, используемое для имитации задержки перед присланным ответом от сервера в тестовом билде.

```gml
#macro YG_SAVING_DEBUG_PERIOD 0.2 // Время сохранения данных в секундах
```

### `YG_SAVING_DEBUG_GENERATE_ERROR_SEND`
Имитировать ошибку сохранения данных на сервер в режиме тестового билда.

```gml
#macro YG_SAVING_DEBUG_GENERATE_ERROR_SEND false // Имитировать ошибку сохранения данных
```

### `YG_SAVING_DEBUG_GENERATE_ERROR_GET`
Имитировать ошибку получения данных сервера в режиме тестового билда.

```gml
#macro YG_SAVING_DEBUG_GENERATE_ERROR_GET false // Имитировать ошибку получения данных
```

## Настройки рекламы

### `YG_INTER_PERIOD`
Периодичность, с которой может показываться реклама в секундах (минимум 90, рекомендуется 91 и выше).

```gml
#macro YG_INTER_PERIOD 91 // Периодичность, с которой может показываться реклама
```

### `YG_INTER_PERIOD_DEBUG`
Периодичность, с которой может показываться фейковая реклама в секундах.

```gml
#macro YG_INTER_PERIOD_DEBUG 10 // Периодичность, с которой может показываться фейковая реклама
```

### `YG_REWARD_DEBUG_TIMER`
Таймер для фейкового реварда, по истечению которого он будет считаться просмотренным.

```gml
#macro YG_REWARD_DEBUG_TIMER 5 // Таймер для фейкового реварда
```

## Настройки файлов

### `YG_DATA_FILENAME`
Имя файла data для дебаг сейвов.

```gml
#macro YG_DATA_FILENAME "__data.json" // Имя файла data для дебаг сейвов
```

### `YG_STATS_FILENAME`
Имя файла stats для дебаг сейвов.

```gml
#macro YG_STATS_FILENAME "__stats.json" // Имя файла stats для дебаг сейвов
```

## Дополнительные настройки

### `YG_ACTIVE_CAMERA_ON`
Использует ли игра активную камеру (в разработке).

```gml
#macro YG_ACTIVE_CAMERA_ON false // Использует ли игра активную камеру
```

## Структуры данных по умолчанию

В файле также определяются структуры данных по умолчанию:

```gml
// Дефолтная data-структура
YG.data.completed_lvls = []
YG.data.available_lvls = [0]

// Дефолтная stats-структура
// YG.stats.something = 123...

// Дефолтные флаги
// YG.flags.something = 123...
```

Эти структуры определяют начальное состояние данных игрока при первом запуске игры.
