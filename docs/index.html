HTML5 Ultra Pack Documentation

HTML5 Ultra Pack - это проект GameMaker Studio, предназначенный для создания HTML5-игр с интеграцией с Yandex Games SDK и PlayGama Bridge. Проект предоставляет комплексное решение для интеграции с платформами публикации игр, включая функции сохранений, рекламы, аудио и платформо-специфичной информации.

Содержание документации

  • Документация по объекту YG - Глобальный объект для интеграции с SDK
  • Настройка конфигурации в файле YGsettings - Обязательные настройки для инициализации YG SDK
  • Хранилище (Storage) - Функции для сохранения и загрузки данных
  • Реклама (Advertising) - Функции для работы с рекламой
  • Аудио - Управление громкостью
  • Платформа - Информация о платформе
  • Примеры использования - Примеры кода
