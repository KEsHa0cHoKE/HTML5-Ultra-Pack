# Настройка конфигурации в файле YGsettings

Файл `YGsettings.gml` содержит глобальные настройки для интеграции с Yandex Games SDK и PlayGama Bridge. Все настройки определяются как макросы в функции `__YGsettings()`.

## Основные настройки

### YG_MODE
- **Значение по умолчанию**: `E_YG_MODE.PLAYGAMA`
- **Описание**: Используемый SDK. Может быть Yandex или PlayGama.

### YG_FIRST_ROOM
- **Значение по умолчанию**: `r_init`
- **Описание**: Стартовая комната вашей игры.

### YG_DEBUG_LANGUAGE
- **Значение по умолчанию**: `"ru"`
- **Описание**: Язык, который будет использован для тестовых билдов и помещён в `YG.lang`.

## Настройки сохранений

### YG_SAVING_ACTIVE
- **Значение по умолчанию**: `true`
- **Описание**: Сохранять данные на сервер в релизном билде (если `false`, то прогресс не сохраняется вообще).

### YG_SAVING_DEBUG_ACTIVE
- **Значение по умолчанию**: `true`
- **Описание**: Имитировать сохранение/загрузку прогресса на сервер в тестовом билде (сохраняет/загружает сейвы в локальные файлы).

### YG_SAVING_DEBUG_PERIOD
- **Значение по умолчанию**: `0.2`
- **Описание**: Время сохранения данных в секундах, используемое для имитации задержки перед полученным ответом от сервера в тестовом билде.

### YG_SAVING_DEBUG_GENERATE_ERROR_SEND
- **Значение по умолчанию**: `false`
- **Описание**: Имитировать ошибку сохранения данных на сервер в режиме тестового билда.

### YG_SAVING_DEBUG_GENERATE_ERROR_GET
- **Значение по умолчанию**: `false`
- **Описание**: Имитировать ошибку получения данных сервера в режиме тестового билда.

## Настройки рекламы

### YG_INTER_PERIOD
- **Значение по умолчанию**: `91`
- **Описание**: Периодичность, с которой может показываться реклама в секундах (минимум 90, рекомендуется 91 и выше).

### YG_INTER_PERIOD_DEBUG
- **Значение по умолчанию**: `10`
- **Описание**: Периодичность, с которой может показываться фейковая реклама в секундах.

### YG_REWARD_DEBUG_TIMER
- **Значение по умолчанию**: `5`
- **Описание**: Таймер для фейкового реварда, по истечению которого он будет считаться просмотренным.

## Настройки файлов

### YG_DATA_FILENAME
- **Значение по умолчанию**: `"__data.json"`
- **Описание**: Имя файла data для дебаг сейвов.

### YG_STATS_FILENAME
- **Значение по умолчанию**: `"__stats.json"`
- **Описание**: Имя файла stats для дебаг сейвов.

## Дополнительные настройки

### YG_ACTIVE_CAMERA_ON
- **Значение по умолчанию**: `false`
- **Описание**: Использует ли игра активную камеру (!В РАЗРАБОТКЕ!).

## Структуры данных по умолчанию

В файле также определены структуры данных по умолчанию:

- `YG.data.completed_lvls` - список пройденных уровней (изначально пустой массив)
- `YG.data.available_lvls` - список доступных уровней (изначально содержит только первый уровень [0])

Также есть закомментированные примеры для:
- `YG.stats.something` - пример для статистики
- `YG.flags.something` - пример для флагов
