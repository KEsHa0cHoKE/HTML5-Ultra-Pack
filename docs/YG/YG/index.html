    Объект YG

    YG - это глобальная структура(struct), служащая единым интерфейсом для взаимодействия со всеми доступными инструментами расширения. Она предоставляет набор методов и свойств, разбитых по модулям

    Модули

    Модуль Тип Описание
    adv Struct Реклама (Interstitial, Rewarded, Banner)
    audio Struct Управление аудио
    platform Struct Информация о платформе
    storage Struct Методы для работы с хранилищами данных

    Свойства

    Свойство Тип Описание
    lang String Язык пользователя в формате ISO 639-1
    device_type E_DEVICE_TYPE Тип устройства пользователя
    is_release_build Bool Указывает, тестовый это билд, или скомпилированный

    Области хранения

    Структуры для хранения данных, которые будут сохраняться между игровыми сессиями на сервере/устройстве игрока

    Свойство Тип Описание
    data Struct Структура для хранения данных пользователя
    stats Struct То же что и data, но может хранить только типы Real. Подробнее
    flags Struct Структура для хранения флагов

    Каждая из этих структур получает и отправляет(кроме flags) значения на сервер либо в локальные файлы. Это подразумевает, что во время инициализации в стартовой комнате значения переменных внутри них будут перезаписаны на полученные с сервера/из файла (если они были помещены туда ранее)

    Воспринимайте их как глобальные переменные, которые сохраняют свои значения между игровыми сессиями

    Инициализируются в YGsettings

    data

    Структура для хранения данных, которые будут храниться на сервере/устройстве игрока

    Типы данных: Real, String, Bool, Array, Struct

    stats

    Внимание

    Поддерживается только для Yandex Games SDK

    То же самое что и data, но имеет возможность чаще получать/отправлять данные, а также хранит только Real значения

    Типы данных: Real

    flags

    Внимание

    Поддерживается только для Yandex Games SDK

    Структура для хранения дефолтных значений флагов. Если флаги не пришли с сервера, или пришли не все флаги, то будут использованы заданные здесь значения

    Типы данных: String

    Внимание

    Приходящие с сервера данные всегда будут строкой(String), поэтому если вы ожидаете на вход число(Real), вам необходимо сконвертировать значение через функцию real()
