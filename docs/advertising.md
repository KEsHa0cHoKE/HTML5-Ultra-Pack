# Реклама (Advertising)

YG предоставляет функции для работы с рекламой на платформах Яндекс Игр и PlayGama.

## Общие функции

### `YG.adv.is_active()`
Возвращает, показывается ли сейчас реклама, или предупреждение о скором показе рекламы, или ревард, или ожидается ответ сервера на запрос показать ревард.

Пример:
```gml
if (YG.adv.is_active()) {
    show_debug_message("Реклама сейчас активна");
} else {
    show_debug_message("Реклама неактивна");
}
```

## Интерститиал (Interstitial)

Интерститиальная реклама - это полноэкранная реклама, которая отображается между уровнями игры или в других подходящих моментах.

### `YG.adv.interstitial.is_showable()`
Возвращает, прошло ли достаточно времени, чтобы можно было показать рекламу.

Пример:
```gml
if (YG.adv.interstitial.is_showable()) {
    YG.adv.interstitial.show();
}
```

### `YG.adv.interstitial.show([callback], [showWarning])`
Показать полноэкранную рекламу.

Параметры:
- `_callback` (Function, опционально) - коллбек, выполнится когда игрок закроет рекламу
- `_showWarning` (Bool, опционально) - если true - запускает предупреждение о скором показе рекламы, а через 2 секунды саму рекламу. False по умолчанию

Пример:
```gml
// Простой показ рекламы
YG.adv.interstitial.show();

// Показ рекламы с коллбеком
YG.adv.interstitial.show(function() {
    show_debug_message("Реклама закрыта, продолжаем игру");
});

// Показ рекламы с предупреждением
YG.adv.interstitial.show(
    function() { show_debug_message("Реклама завершена"); }, 
    true // Показать предупреждение перед рекламой
);
```

## Ревард (Reward)

Ревард - это видео-реклама, за которую игроки получают награду (например, монеты, жизни и т.д.).

### `YG.adv.reward.show(callback, [callbackWithoutReward])`
Запускает ревард. В аргументе указывается метод/функция, которая выполнится при успешном просмотре реварда.

Параметры:
- `_callback` (Function) - коллбек, если игрок досмотрел рекламу
- `_callbackWithoutReward` (Function, опционально) - коллбек, если игрок закрыл рекламу прежде чем она закончилась

Пример:
```gml
// Показываем ревард с коллбеком
YG.adv.reward.show(
    function() { 
        // Игрок посмотрел рекламу до конца
        player.coins += 100;
        show_debug_message("Вы получили 100 монет за просмотр рекламы!");
    },
    function() { 
        // Игрок закрыл рекламу раньше времени
        show_debug_message("Вы закрыли рекламу слишком рано, награда не начислена");
    }
);
