# Аудио

YG предоставляет функции для управления громкостью аудио в игре, независимо от состояния рекламы.

## `YG.audio.getVolume()`
Возвращает уровень громкости главного аудиоканала (без учёта отключения звука во время рекламы).

Пример:
```gml
var current_volume = YG.audio.getVolume();
show_debug_message("Текущая громкость: " + string(current_volume));
```

## `YG.audio.setVolume(value)`
Устанавливает уровень громкости для главного аудиоканала (без учёта отключения звука во время рекламы).

Параметры:
- `_value` (Real) - значение громкости в диапазоне от 0.0 (без звука) до 1.0 (максимальная громкость)

Пример:
```gml
// Устанавливаем громкость на 50%
YG.audio.setVolume(0.5);

// Получаем текущую громкость и немного увеличиваем её
var current_vol = YG.audio.getVolume();
YG.audio.setVolume(min(1.0, current_vol + 0.1));
```

Важно помнить, что во время показа рекламы звук может быть отключен системой, независимо от установленного значения громкости через `YG.audio.setVolume()`. После завершения рекламы громкость восстановится к установленному значению.
