# Документация HTML5 Ultra Pack

HTML5 Ultra Pack - это проект GameMaker Studio, предназначенный для создания HTML5-игр с интеграцией с Yandex Games SDK и PlayGama Bridge. Проект предоставляет комплексное решение для интеграции с платформами публикации игр, включая функции сохранений, рекламы, аудио и платформо-специфичной информации.
