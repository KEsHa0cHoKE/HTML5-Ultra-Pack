# Архитектурный анализ проекта HTML5 Ultra Pack

## Общее описание
HTML5 Ultra Pack - это проект GameMaker Studio, предназначенный для создания HTML5-игр с интеграцией с Yandex Games SDK и PlayGama Bridge. Проект предоставляет комплексное решение для интеграции с платформами публикации игр, включая функции сохранений, рекламы, аудио и платформо-специфичной информации.

## Структура проекта

### Основные компоненты

1. **YaGames SDK Extension** ([extensions/YaGames/YaGames.js](extensions/YaGames/YaGames.js:1))
   - JavaScript-расширение для интеграции с Yandex Games SDK
   - Обеспечивает функции рекламы, сохранений, получения информации о пользователе и устройствах
   - Включает более 100 функций для взаимодействия с SDK

2. **Объект инициализации** ([objects/__objYGInit/__objYGInit.yy](objects/__objYGInit/__objYGInit.yy))
   - Основной объект инициализации YG SDK
   - Управляет последовательностью инициализации: SDK → Environment → Player → Stats → Data → Flags
   - Обрабатывает различные состояния инициализации через enum E_INIT_STATE

3. **Глобальная структура YG** ([scripts/__YGmacros/__YGmacros.gml](scripts/__YGmacros/__YGmacros.gml:1))
   - Центральный объект для доступа ко всем функциям SDK
   - Содержит поля: data, stats, flags, lang, device_type, is_release_build
   - Обеспечивает унифицированный интерфейс к функциям сохранений, рекламы и аудио

4. **Настройки проекта** ([scripts/YGsettings/YGsettings.gml](scripts/YGsettings/YGsettings.gml:1))
   - Макросы для конфигурации SDK
   - Параметры: YG_MODE, YG_FIRST_ROOM, YG_DEBUG_LANGUAGE, настройки сохранений и рекламы
   - Позволяет настраивать поведение в тестовом и релизном режимах

### Ключевые объекты

1. **Реклама** ([objects/__ygAdv/__ygAdv.yy](objects/__ygAdv/__ygAdv.yy))
   - Управление показом интерстициальной и вознаграждаемой рекламы
   - Поддержка фейковой рекламы в тестовом режиме
   - Конструкторы для имитации рекламы с таймерами интерфейсом

2. **Сохранения** ([objects/__ygData/__ygData.yy](objects/__ygData/__ygData.yy))
   - Методы отправки и получения данных (data и stats)
   - Поддержка PlayGama и Yandex Games SDK
   - Режимы работы: релизный (серверные сохранения) и тестовый (локальные файлы)

3. **Аудио** ([objects/__ygAudio/__ygAudio.yy](objects/__ygAudio/__ygAudio.yy))
   - Управление громкостью аудио
   - Временное отключение звука во время рекламы

4. **Прослушиватель событий** ([objects/__ygEventListener/__ygEventListener.yy](objects/__ygEventListener/__ygEventListener.yy))
   - Обработка асинхронных событий от SDK
   - Обработка событий рекламы, сохранений и других асинхронных операций

### Поддерживаемые функции

1. **Реклама**
   - Интерстициальная реклама (с таймером периодичности)
   - Вознаграждаемая реклама (с таймером просмотра)
   - Поддержка фейковой рекламы в тестовом режиме

2. **Сохранения**
   - Сохранение и загрузка пользовательских данных (data)
   - Сохранение и загрузка облегчённых пользовательских данных. Их можно сохранять чаще, но значения ключей могут быть только числами (stats)
   - Поддержка PlayGama и Yandex Games SDK
   - Локальные файлы для тестирования

3. **Платформенная интеграция**
   - Получение информации о пользователе (ID, имя, фото)
   - Получение информации об устройстве (тип, язык)
   - Поддержка таблиц рекордов
   - Встроенные покупки (для Yandex Games)

4. **Аудио**
   - Управление громкостью
   - Автоматическое отключение во время рекламы

### Архитектурные особенности

1. **Поддержка двух режимов работы**
   - Yandex Games SDK
   - PlayGama Bridge

2. **Тестовый и релизный режимы**
   - В тестовом режиме используются локальные файлы вместо серверных сохранений
   - В тестовом режиме показывается фейковая реклама
   - Возможность имитации ошибок для тестирования

3. **Асинхронная архитектура**
   - Все операции с SDK асинхронны
   - Использование коллбеков для обработки результатов
   - Обработка через асинхронные события GameMaker

4. **Модульная структура**
   - Каждый компонент (реклама, сохранения, аудио) изолирован в отдельные объекты
   - Единый интерфейс через глобальный объект YG

Этот проект представляет собой хорошо структурированное решение для интеграции HTML5-игр с платформами публикации, обеспечивая разработчикам удобный интерфейс для работы с различными SDK и функциями публикации.
