# Платформа

`platform` предоставляет информацию о текущей платформе и состоянии игры

## Свойства

| Свойство         | Тип                     | Описание                                                     |
| ---------------- | ----------------------- | ------------------------------------------------------------ |
| id               | `String(PG_PLATFORM_*)` | [ID платформы](../Поддерживаемые.md)                               |
| is_audio_enabled | `Bool`                  | Включен ли звук на платформе (Всегда `true` если Yandex SDK) |
| is_paused        | `Bool`                  | Приостановлена ли игра                                       |
| is_visible       | `Bool`                  | Открыта ли вкладка с игрой (Всегда `true` если Yandex SDK)   |
