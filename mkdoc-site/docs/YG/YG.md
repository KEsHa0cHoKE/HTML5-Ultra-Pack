# Объект YG

**`YG`** - это глобальная структура(`struct`), служащая единым интерфейсом для взаимодействия со всеми доступными инструментами расширения. Она предоставляет набор методов и свойств, разбитых по модулям

## Модули

| Модуль       | Тип      | Описание                                 |
| ------------ | -------- | ---------------------------------------- |
| [adv](adv/adv.md)      | `Struct` | Реклама (Interstitial, Rewarded, Banner) |
| [audio](audio.md)    | `Struct` | Управление аудио                         |
| [platform](platform.md) | `Struct` | Информация о платформе                   |
| [storage](storage/storage.md)  | `Struct` | Методы для работы с хранилищами данных   |

## Свойства

| Свойство         | Тип             | Описание                                                                                      |
| ---------------- | --------------- | --------------------------------------------------------------------------------------------- |
| lang             | `String`        | Язык пользователя в формате [ISO 639-1](https://ru.wikipedia.org/wiki/Список_кодов_ISO_639-1) |
| device_type      | `E_DEVICE_TYPE` | Тип устройства пользователя                                                                   |
| is_release_build | `Bool`          | Указывает, тестовый это билд, или скомпилированный                                            |

***

## Области хранения

> Структуры для хранения данных, которые будут сохраняться между игровыми сессиями на сервере/устройстве игрока

| Свойство        | Тип      | Описание                                                |
| --------------- | -------- | ------------------------------------------------------- |
| data   | `Struct` | Структура для хранения данных пользователя              |
| stats | `Struct` | То же что и `data`, но может хранить только типы `Real`. [Подробнее](https://yandex.ru/dev/games/doc/ru/sdk/sdk-player#ingame-data) |
| flags | `Struct` | Структура для хранения флагов                           |

Каждая из этих структур взаимодействует с сервером/локальными файлами. Это подразумевает, что во время инициализации SDK (процессы, происходящие в стартовой комнате - \_\_rInit) значения переменных внутри них будут перезаписаны на полученные с сервера/из файла (если они были помещены туда ранее).

**Воспринимайте их как глобальные переменные, которые сохраняют свои значения между игровыми сессиями.**

**Инициализируются в [YGsettings](../YGsettings.md)**

***

#### data

> Структура для хранения данных, которые будут храниться на сервере/устройстве игрока.

**Типы данных:** `Real`, `String`, `Bool`, `Array`, `Struct`

***

#### stats

!!! warning "Внимание"
    Поддерживается только для Yandex Games SDK

!!! tip "Подсказка"
    Если вы не уверены, нужно ли оно вам в вашей игре - скорее всего нет, можете игнорировать :)

> То же самое что и `data`, но имеет преимущество в виде возможности чаще запрашивать/отправлять данные на сервер. Лучше подходит для часто изменяющихся данных.

**Типы данных:** `Real`

***

#### flags

!!! warning "Внимание"
    Поддерживается только для Yandex Games SDK


> Структура для хранения дефолтных значений флагов. Если флаги не пришли с сервера, или пришли не все флаги, то будут использованы заданные здесь значения.

**Типы данных:** `String`

!!! warning "Внимание"
    Приходящие с сервера данные всегда будут строкой(`String`), поэтому если вы ожидаете на вход число(`Real`), вам необходимо сконвертировать значение через функцию `real()`
