# Баннер

Модуль для работы с баннерной рекламой (sticky-баннер, накладывается поверх игры)

## Свойства

| Свойство     | Тип               | Описание                                           |
| ------------ | ----------------- | -------------------------------------------------- |
| is_supported | `Bool`            | Поддерживается ли этот тип рекламы на площадке     |
| is_active    | `Bool`            | Отображается ли баннер в данный момент             |
| position     | `E_BANNER_PG_POS` | Позиция баннера (влияет только на playgama bridge) |

## Методы

| Метод               | Возвращаемый тип | Описание                                                                                             |
| ------------------- | ---------------- | ---------------------------------------------------------------------------------------------------- |
| [show](#show-undefined)                | `Undefined`      | Отображает баннер                                                                                    |
| [hide](#hide-undefined)                | `Undefined`      | Скрывает баннер                                                                                      |
| [get_height_playgama](#get_height_playgama-real) | `Real`           | Возвращает высоту баннера (таким, каким он был бы в playgama bridge) с учётом размеров игрового окна |

---

### `show()` → `Undefined`

> Отображает баннер

| Параметр                           | Тип               | Описание                                      |
| ---------------------------------- | ----------------- | --------------------------------------------- |
| _(опционально)_ `_pgBannerPosEnum` | `E_BANNER_PG_POS` | Позиция (E_BANNER_PG_POS.BOTTOM по умолчанию) |

**Пример:**

```js
YG.adv.banner.show();
```

---

### `hide()` → `Undefined`

> Скрывает баннер

**Пример:**

```js
YG.adv.banner.hide();
```

---

### `get_height_playgama()` → `Real`

> Возвращает высоту баннера (таким, каким он был бы в playgama bridge) с учётом размеров игрового окна

**Пример:**

```js
var _bannerHeight = YG.adv.banner.get_height_playgama();
```
