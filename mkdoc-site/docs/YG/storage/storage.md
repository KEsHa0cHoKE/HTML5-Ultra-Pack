# Хранилище

`storage` предоставляет модули для сохранения и загрузки данных пользователя на сервер платформы или в локальные файлы при тестовом билде.

## Модули

| Модуль    | Тип      | Описание                                 |
| --------- | -------- | ---------------------------------------- |
| [data](data.md)  | `Struct` | Данные игрока |
| [stats](stats.md) | `Struct` | То же что и `data`, но с [отличиями](https://yandex.ru/dev/games/doc/ru/sdk/sdk-player#ingame-data) |                         |
