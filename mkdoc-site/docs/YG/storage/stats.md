# Данные игрока

`stats` модуль предоставляет методы для работы с хранилищем данных с аналогичным названием

!!! warning "Важно"
    Данный модуль не доступен в PlayGama SDK
!!! tip "Совет"
    Если вы не очень понимаете зачем нужен `stats`, когда уже есть `data` то можете смело игнорировать данный модуль

## Свойства

| Свойство     | Тип    | Описание                                                                                         |
| ------------ | ------ | ------------------------------------------------------------------------------------------------ |
| is_supported | `Bool` | Доступно ли хранилище на платформе (Для Yandex Games SDK всегда true, для PlayGama всегда false) |

## Методы

| Метод     | Возвращаемый тип | Описание                                                    |
| --------- | ---------------- | ----------------------------------------------------------- |
| [send](#send-undefined)      | `Undefined`      | Отправляет структуру `YG.stats` на сервер/в локальные файлы |
| [get](#get-undefined)       | `Undefined`      | Асинхронно получает данные `stats` с сервера/файлов         |
| [deleteAll](#deleteall-undefined) | `Undefined`      | Удаляет все сохраненные данные                              |

***

### `send()` → `Undefined`

> Отправляет структуру `YG.stats` на сервер платформы, либо в локальные файлы в тестовом билде.

| Параметр                          | Тип        | Описание                             |
| --------------------------------- | ---------- | ------------------------------------ |
| *(опционально)* `_callback`       | `Function` | Коллбек при успешной отправке данных |
| *(опционально)* `_callbackFailed` | `Function` | Коллбек при неудаче                  |

**Пример:**
```js
YG.stats.level = 5;
YG.stats.score = 1000;
YG.storage.stats.send(
    function() { show_debug_message("Данные успешно сохранены"); },
    function() { show_debug_message("Ошибка сохранения"); }
);
```

***

### `get()` → `Undefined`

!!! tip "Совет"
    В обычных сценариях использования вам не нужно вызывать этот метод, поскольку при инициализации SDK структура `YG.stats` синхронизирует значения переменных с сервером автоматически

> Асинхронно получает данные `data` с сервера платформы или из локальных файлов в тестовом билде. Значения полученных переменных перезапишут собой значения в в структуре `YG.data`

| Параметр                          | Тип        | Описание                              |
| --------------------------------- | ---------- | ------------------------------------- |
| *(опционально)* `_callback`       | `Function` | Коллбек при успешном получении данных |
| *(опционально)* `_callbackFailed` | `Function` | Коллбек при неудаче                   |

 **Пример:**
```js
YG.storage.stats.get(
    function() { show_debug_message("Данные успешно загружены: " + string(YG.stats)); },
    function() { show_debug_message("Ошибка загрузки"); }
);
```

***

### `deleteAll()` → `Undefined`

> Отправляет на сервер платформы или в локальный файл пустую структуру, которая перезапишет собой сейвы, удалив их.

**Пример:**
```js
YG.storage.stats.deleteAll();
```
