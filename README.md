# HTML5 Ultra Pack

**HTML5 Ultra Pack** — это набор инструментов для работы с `HTML5` целью в `GameMaker`.

Помимо общих утилит, полезных для веба в целом, включает объединение `Yandex Games SDK` и `Playgama Bridge` под единым интерфейсом, позволяющим моментально переключить используемый SDK без написания дополнительного кода.

## Возможности

- **Система моков** — протестируй поведение рекламы, сохранений, звука без загрузки игры на сервисы. Добавляется отрисовка фейковой рекламы, которая ведёт себя аналогично реальной. То же и с сохранениями — они будут работать аналогично поведению на реальных сервисах. Игра сама определит если она запущена на сервисе и заменит фейковый функционал на реальный

- **Автоматизация инициализации SDK** — не нужно самостоятельно прописывать логику загрузки SDK. После автоматической инициализации все переменные платформ, такие как сохранения, флаги и язык — будут доступны через глобальную структуру

- **Моментальная смена SDK** — делаешь игру с использованием `Yandex Games SDK`, затем в несколько действий меняешь SDK и можно загружать игру на другие платформы, доступные с `Playgama Bridge`

- **Система сохранений** — обёртка над функционалом облачных и локальных сохранений `Yandex Games SDK` и `Playgama Bridge`, упрощающее работу с функциями до одного метода

- **Реклама** — обёртка над функционалом вызова полноэкранной, ревард и баннерной рекламы `Yandex Games SDK` и `Playgama Bridge`, упрощающее работу с функциями до одного метода

- **Управление аудио** — контроль громкости звука, который автоматически реагирует на рекламу, смену вкладки и т.д. включаясь и отключаясь согласно требованиям площадок

- **Оптимизация веса билда и скорости загрузки** — использование `web dynamic textures` от **YellowAfterLife** для ускорения загрузки игр

- **Устранено размытие** — использование `hdpi+` от **YellowAfterLife** для устранения размытия изображения

- **Автоматическая адаптация** — использование `Aвто - масштабирование` от **GMLab**, которое контролирует камеру для адаптации игры под различные пропорции и разрешения экранов (если в вашей игре камера статична)

- **Готовый прелоадер** — колесо загрузки перед открытием игры
